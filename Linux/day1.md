# Introduction to DevOps & IT Workflow

---

## Introduction to DevOps

**DevOps** is a culture and practice that combines **Development (Dev)** and **Operations (Ops)** to deliver applications faster, more reliably, and with better quality.

### DevOps focuses on:
- Continuous Integration (CI)
- Continuous Delivery (CD)
- Automation
- Monitoring
- Collaboration between teams

---

## How an IT Company Works

Typical workflow in an IT company:

1. Client gives requirements  
2. Business Analyst (BA) prepares documentation  
3. Developers write code  
4. Testers test the application  
5. DevOps deploys the application  
6. Support team monitors and maintains

---

## What is an Application?

An **Application** is a software program used to perform tasks.

| Type | Example |
|----|--------|
| Web Application | Amazon, Flipkart |
| Mobile App | WhatsApp |
| Desktop App | MS Word |
| Cloud Application | Gmail, Google Drive |

---

## Developers vs Testers vs DevOps

| Role | Responsibilities |
|----|----------------|
| Developer | Writes application code |
| Tester | Finds bugs and verifies quality |
| DevOps | Automates deployment & manages servers |

---

## DevOps Lifecycle

```text
PLAN → CODE → BUILD → TEST → RELEASE → DEPLOY → OPERATE → MONITOR
```
