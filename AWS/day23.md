## introducation to cloudwatch 
- CloudWatch is a monitoring and management service provided by AWS.

## dashboard in cloudwatch
 - A customizable home page in CloudWatch that provides an overview of your AWS resources and applications.
## matrics in cloudwatch
numerical data points collected from AWS resources and services.
 - Examples: CPU utilization

## alarms in cloudwatch
 - Notifications based on metric thresholds.
 - Trigger actions when certain conditions are met.
   - Examples: sending notifications when CPU utilization exceeds a certain percentage.
```
A metric alarm has the following possible states:

OK – The metric or expression is within the defined threshold.
ALARM – The metric or expression is outside of the defined threshold.
INSUFFICIENT_DATA – The alarm has just started, the metric is not available, or not enough data is available for the metric to determine the alarm state.
```
