## what is Load balancer 
  to distribute the traffic to multiple servers to handle the load and to provide high availability and fault tolerance.


types of load balancer 
1. classic load balancer ---> old , http and https and tcp and udp  
2. application load balancer ---> http and https, osi model application layer (L7) , path based and host based routing 

3. network load balancer ---> tcp and udp, osi model transport layer (L4) , high performance and low latency
4. gateway load balancer --->layer 3 , to deploy and manage third party virtual appliances, such as firewalls, intrusion detection and prevention systems, and deep packet inspection systems. protocal GENEVE.
